# TheTwentyGoods free website package

This is a static website that can be hosted free using GitHub Pages.

## Included
- Home, Shop, About, Contact
- Terms & Conditions
- Privacy Policy
- Refund & Return Policy
- Responsive styling

## Publish free with GitHub Pages
1. Sign in to https://github.com/ or create a free account.
2. Create a new public repository named `thetwentygoods`.
3. Upload all files in this folder (index.html must be in the repository root).
4. Open repository Settings -> Pages.
5. Under Build and deployment, choose Deploy from a branch.
6. Select `main` and `/ (root)`, then Save.
7. GitHub will provide a free address similar to `https://YOUR-USERNAME.github.io/thetwentygoods/`.

## Important before PayHere review
The Shop page is intentionally not populated with made-up products or prices. Add actual products, accurate descriptions, photographs, stock status and LKR selling prices before submitting the website to PayHere. PayHere says websites with mock products, incomplete content or missing business contact/policy information may be rejected.

Also add/confirm the full business phone number and address as requested by PayHere. The supplied address is shown as: 70, Peiris Avenue, Kalubowila, Sri Lanka. Confirm that this is the correct postal address and add any missing locality/postal details if needed.

This package does not itself activate PayHere or create a checkout integration. Add your approved PayHere payment link or checkout flow after your merchant account is activated. Until then, the website offers WhatsApp ordering and describes PayHere as a payment method subject to availability/confirmation.

## Updating product prices
Edit `shop.html` to add real product cards. For each item include:
- Product name and exact model/compatibility
- Actual product image
- Description/specifications
- Current selling price in LKR
- Availability
- Clear order/contact action

Update prices whenever your selling prices change. Do not leave demo/template product prices on the live site.
